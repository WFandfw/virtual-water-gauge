# 水槽验证数据集

用于验证「虚拟水尺水位视觉监测系统」分割精度与水位线提取精度的标注数据集。
共 **1188 组**带人工标注的样本，覆盖混凝土、浆砌石、砂石三类边坡与十五里河河道场景。

```

│   ├── 0000/ … 0093/      每个样本一个文件夹
│   │   ├── original.jpg      原始图像（195 × 600，灰度）
│   │   ├── mask_orig.jpg     水体掩码

│   └── 水位线Y坐标.xlsx     人工标注表
```

## 二、样本与标注

| 子集 | 样本数 | 标注文件 | 标注字段 |
|---|---|---|---|
| 混凝土数据 | 94 | `水位线Y坐标.xlsx` | 序号、模型坐标、人工坐标、误差 |
| 浆砌石数据 | 197 | `水位线Y坐标.xlsx` | 同上 |
| 砂石数据 | 102 | `水位线Y坐标.xlsx` | 同上 |
| 十五里河数据集 | 795 | `挑选图片信息.xlsx` | 编号、测量水位线、理论值、差值、绝对差值 |
| **合计** | **1188** | | |

字段含义：

- **人工坐标**：人工目视判读得到的水位线像素纵坐标 y（像素，原点在图像顶部）。
- **模型坐标**：系统输出的水位线像素纵坐标 y。
- **误差**：标注表中该列为空，使用时应按 `模型坐标 − 人工坐标` 现算，避免与旧记录混淆。
- 十五里河子集的 **理论值** 由现场实体水尺读数换算得到的参考像素位置，**测量水位线** 为系统输出，二者之差即像素误差。

样本图像统一为 **195 × 600**（三类边坡）与 **100 × 1000 为主**（十五里河），
灰度、纵向长条比例，与边缘端 OpenMV 采集并经相机链裁剪后的视场一致。

## 四、采集与标注方式

- **采集设备**：OpenMV RT1062 摄像头，SVGA 视场（800×600），灰度输出；经相机标定与畸变校正后按监测断面裁剪，得到纵向长条图像。
- **采集场景**：室内水槽与试验渠（可控水位）、野外边坡（混凝土 / 浆砌石 / 砂石）、河道（十五里河）。
- **标注方式**：由队员逐张目视判读水陆交界位置，记录水位线的像素纵坐标；同一张图由同一人完成判读，判读结果抽样复核。
- **真值口径**：像素坐标为图像空间真值，未做米制换算；米制精度需配合各测点的标定查找表（`calibration/*.csv`）另行验证。

## 五、已知问题与使用注意

1. **砂石子集精度偏低**（MAE 5.53 px，≤5 px 仅 59.8%），原因是该坡面反光强、水面纹理弱，属数据集本身的场景难度，不是标注错误。
2. **序号 0091—0097 连续 7 个样本误差偏大**（13—16 px），推测为同一场次水位未稳定时采集，如需严格统计可单独剔除并说明。
3. **十五里河原图尺寸不统一**：721 张 100×1000、58 张 100×926、16 张 120×1000；批处理时请按目录读取全部文件，不要用 `*.jpg` 过滤（该目录内 PNG 与 JPG 混存）。
4. **十五里河分割图为放大渲染**（189×1907 / 199×1907），与 1000 高的原图不是同一坐标系，**不能与原图逐像素直接对齐**；像素误差请以标注表中的数值为准。
5. 砂石 0291、0292 两组因缺人工标注，已从数据集中移除；砂石子集编号为 **0293—0394（102 组）**，与标注表行数一致。
6. `manifest.csv` 记录的是**本目录下全部图片**的 SHA256（含掩码与结果图，共 2769 个文件）；仓库中的轻量版（仅原图、已转 JPG）会附带它自己的清单（1188 个文件）。两份清单各自独立，校验时以同目录下的文件为准。

## 六、隐私与数据使用边界

- 图像内容为水槽、渠道与河道水面及边坡，**不含人脸、车牌、门牌等个人信息**；采集时未对特定个人进行拍摄。
- 如后续替换或新增样本，须确保画面中不含可识别个人身份的内容；若无法避免，应对相应区域做模糊处理后再纳入。
- 本数据集**仅用于水位视觉测量的算法研究与验证**，不得用于人脸识别、行为分析等超出采集目的用途。
- 数据集不含任何服务器地址、账号、密钥等访问凭据。
