## 自研内容总述（自研边界）

- 虚拟水尺分段线性标定（`ruler.py`，CSV 像素→高程换算，支持不规则边坡的非线性映射）
- 水位线提取与掩码后处理（`sam3first.py` 阈值/形态学/连通域分析、双路掩码择优）
- MobileNet-SSD 框提示融合（自训水体/岸框检测 → SAM3 正负框提示；无框时退回纯语义提示）
- MobileNet-SSD 水体检测模型的训练（自标注数据，两份权重分别对应两套标定站号）
- 多帧筛选与视频关键帧传播（`main_video.py` / `time_tracker.py` / `sam3video.py`）
- 异常帧过滤与自动控制联动（`control_first.py`）
- 端云协同架构（OpenMV 采集 → TCP 上传 → 云端分割 → WebSocket 推流）
- 前端页面与交互（`web/`）
- 验证数据集与评测脚本（`水槽数据集/`、`eval_kit/`）
